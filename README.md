# spa-gestao-documento-terceiro

## Objetivos

SPA para centralizar a gestão de documento de terceiros

## Requisitos
- Node.js (versão 12 ou superior)
- npm (gerenciador de pacotes do Node.js)

## Executando o projeto

```bash
npm install
npm run dev
```
Agora você pode acessar o seu aplicativo em http://localhost:3000.
ou na porta definida no terminal, pois o nextjs se adapta conforme portes ja utilizadas


## Variáveis de Ambiente

```bash
VERSION=1.0.0
ENVIRONMENT=development
SENTRY_DSN=
AUTH_SECRET=
API_BFF_GESTAO_DOCUMENTO_TERCEIRO_HOST=
API_BFF_GESTAO_DOCUMENTO_TERCEIRO_SECRET=
HELP_HOST=
```
